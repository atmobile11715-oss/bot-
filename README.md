# Discord Queue Bot Template (ไทย)

เทมเพลตนี้เป็นตัวอย่างบอท Discord (Node.js, discord.js v14) ที่ให้คุณสร้างระบบจองคิวผ่านคำสั่งสแลช พร้อมปุ่ม (Join / Leave) ที่จะเปิดใช้งานตามเวลาที่ตั้งไว้ และปิดเมื่อเต็ม

ฟีเจอร์หลัก
- คำสั่งสแลช: /reserve (ชื่อท้องถิ่น: จองคิว)
- ตั้งชื่อคิว, จำนวนช่อง (max), เวลาหน่วงก่อนเปิด (start_in_minutes), ข้อความอธิบาย
- ปุ่ม Join/Leave ใต้ข้อความคิว — ปุ่มจะถูกปิดจนกว่าจะถึงเวลาเริ่ม
- ถ้าเต็มก่อนเวลา จะปิดคิวทันที
- เมื่อคนจอง จะเห็นลำดับคิวของตัวเอง
- ข้อมูลคิวเก็บแบบไฟล์ JSON (queues.json) เพื่อให้ยังคงข้อมูลได้เมื่อรีสตาร์ท (ไฟล์ถูกใส่ใน .gitignore หลังสร้าง)

การตั้งค่า (ก่อนรัน)
1. สร้างแอป/บอทที่ Discord Developer Portal แล้วเอา TOKEN และ CLIENT_ID รวมทั้ง GUILD_ID (ชั่วคราวสำหรับลงทะเบียนคำสั่งแบบ guild)
2. ใน repo/สภาพแวดล้อมเครื่อง ให้ตั้งตัวแปรแวดล้อม:
   - DISCORD_TOKEN
   - CLIENT_ID
   - GUILD_ID

ตัวอย่าง (Linux/macOS):

```bash
export DISCORD_TOKEN="your_token_here"
export CLIENT_ID="your_client_id_here"
export GUILD_ID="your_guild_id_here"
```

การติดตั้งและลงทะเบียนคำสั่ง

1. ติดตั้ง dependency:
   npm install
2. ลงทะเบียนสแลชคอมมานด์ (รันครั้งเดียวเมื่อพัฒนา/อัปเดตคำสั่ง):
   npm run deploy-commands
3. รันบอท:
   npm start

การใช้งาน
- ในเซิร์ฟเวอร์ที่ลงทะเบียนคำสั่ง พิมพ์ /จองคิว (หรือ /reserve) กรอกพารามิเตอร์
- บอทจะโพสต์ข้อความคิวพร้อมปุ่ม ในช่วงเวลาที่กำหนดปุ่มจะถูกเปิดให้กด
- ผู้ใช้กด Join เพื่อจอง จะได้รับตำแหน่งคิวในข้อความตอบกลับแบบ ephemeral

หมายเหตุ
- ชื่อสแลชคอมมานด์ใช้ชื่อ ASCII (reserve) แต่มีการตั้ง name_localizations เป็นภาษาไทย เพื่อให้ผู้ใช้เห็น /จองคิว
- โค้ดตัวอย่างเก็บข้อมูลในไฟล์ queues.json; ในการใช้งานจริงแนะนำเก็บในฐานข้อมูล (SQLite/Postgres/Mongo) หากต้องการความทนทาน

ถ้าต้องการ ผมสามารถปรับให้ใช้เวลารูปแบบ ISO, เพิ่ม DM แจ้งเตือน, หรือลงทะเบียนคำสั่งเป็น global command ให้ — บอกผมได้เลย
